# Desafio 03 — Tabuada Interativa

## Enunciado

Uma professora quer uma ferramenta simples para gerar tabuadas de
multiplicação para seus alunos praticarem.

**Objetivo:** criar um programa que:

1. Peça ao usuário para informar um número inteiro.
2. Utilize uma estrutura de repetição `for` para calcular e mostrar a
   tabuada desse número, de 1 a 10 (ex.: `7 x 1 = 7`, `7 x 2 = 14`, ...).
3. Ao final da tabuada, pergunte se o usuário deseja gerar outra tabuada,
   usando um laço `while` para repetir o processo enquanto a resposta for
   "sim".
4. Utilize `break` para encerrar o programa caso o usuário informe "não".
