# Desafio 01 — Conversor de Temperaturas

## Enunciado

Um posto de pesquisa climática registrou as seguintes temperaturas do dia,
em graus Celsius:

| Horário | Temperatura (°C) |
|---------|-------------------|
| 06h     | 14.5              |
| 12h     | 27.0              |
| 18h     | 21.3              |
| 00h     | 16.8              |

**Objetivo:** criar um programa que:

1. Armazene os horários e as temperaturas em Celsius.
2. Converta cada temperatura para Fahrenheit, usando a fórmula `F = C * 9/5 + 32`.
3. Identifique qual foi o horário com a maior temperatura registrada.
4. Mostre no terminal uma tabela com horário, temperatura em Celsius e em
   Fahrenheit, seguida do horário de pico.
